The Islands

Indonesia is an archipelago countri that has more than 17.000++ islands and 62% of seas area.

There are 7 main islands, Sumatera, Kalimantan, Java, Sulawesi, Papua, Kepulauan Maluku, Kepulauan Sunda Kecil
